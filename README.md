#  Global Superstore Sales Dashboard

##  Project Overview

The **Global Superstore Sales Dashboard** is a Business Intelligence and Data Analytics project created to analyze sales and profit data of a global retail superstore.

The main purpose of this project is to convert raw sales data into an **interactive and easy-to-understand dashboard**. The dashboard helps users understand sales performance based on **country, category, year, sales, and profit**.

It provides a visual way to identify which products and countries are performing well and which areas may need improvement.

##  Purpose of the Project

The main purposes of this project are:

* To analyze overall sales performance.
* To understand profit generated by the business.
* To compare sales between different countries.
* To compare different product categories.
* To identify the best-performing categories.
* To analyze sales trends over different years.
* To identify high and low sales periods.
* To make business data easier to understand using charts and graphs.
* To help management make better business decisions.
* To create an interactive dashboard instead of analyzing large amounts of raw data manually.

## Problem Statement

A superstore generates a large amount of sales data from different countries, products, categories, and years.

Looking at the raw data makes it difficult to quickly answer questions such as:

* Which country has the highest sales?
* Which product category performs best?
* How much total sales has the company generated?
* How much profit has been earned?
* Are sales increasing or decreasing over time?
* Which countries have lower sales?
* Which category should receive more attention?
* What are the major sales trends?

This project solves these problems by presenting the information in a **visual and interactive dashboard**.

## Project Objectives

The objectives of this project are:

# Data Preparation

Before creating the dashboard, the data needs to be checked and prepared.

### 1. Removing Duplicate Data

Duplicate records can affect the accuracy of sales and profit calculations.

Duplicate rows were identified and removed where necessary.

**Purpose:**
To make sure the same transaction is not counted more than once.

### 2. Handling Missing Values

The dataset was checked for missing or blank values.

Important fields such as:

* Country
* Category
* Sales
* Profit
* Order Date

were checked because missing values in these fields can affect analysis.

Where appropriate, missing values were handled or excluded from calculations.

### 3. Correcting Data Types

Different columns need appropriate data types.

For example:

* Order Date → Date
* Sales → Number
* Profit → Number
* Country → Text
* Category → Text

Correct data types are important for creating accurate calculations and charts.

### 4. Checking Data Consistency

The data was checked for inconsistent spelling, unnecessary spaces, and formatting issues.

For example, country and category names should be written consistently so that they are not treated as separate values.

# How the Project Was Created

The project was developed through the following steps:

## Step 1 – Collect the Dataset

The Global Superstore sales dataset was collected in a structured format such as Excel or CSV.

### Step 2 – Understand the Data

The columns and their meanings were studied.

For example:

* Country tells where the sale occurred.
* Category tells the type of product.
* Sales tells the sales amount.
* Profit tells the profit generated.
* Order Date tells when the transaction occurred.

### Step 3 – Clean the Data

The data was checked for:

* Duplicate records
* Missing values
* Incorrect data types
* Inconsistent names
* Blank values
* Formatting problems

### Step 4 – Connect the Data

The cleaned dataset was connected to the Business Intelligence visualization tool.

### Step 5 – Create Calculations

Important measures such as:

* Total Sales
* Total Profit
* Average Sales

were calculated.

For example:

**Total Sales = Sum of Sales**

**Total Profit = Sum of Profit**

**Average Sales = Average of Sales**

### Step 6 – Create Visualizations

Different charts were created to represent the data.

These include:

* Line chart
* Bar chart
* Country/category comparison
* Data table
* KPI cards
* Filters/slicers

### Step 7 – Create the Dashboard

All important visualizations were arranged together on one dashboard.

The dashboard was designed so that users can quickly understand the company's performance.

### Step 8 – Add Filters

Interactive filters were added for:

* Country
* Region
* Category

This allows users to perform customized analysis.

### Step 9 – Dashboard Formatting

The dashboard was formatted using:

* Consistent fonts
* Titles
* KPI cards
* Charts
* Tables
* Filters
* Background design

The purpose of formatting was to make the dashboard more attractive and easier to understand.

### Step 10 – Analyze the Results

Finally, the dashboard was used to identify important business insights and sales trends.
